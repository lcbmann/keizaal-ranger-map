    The Ranger Corps - Field Atlas

    Share What You Find

    This atlas is a field copy for sharing useful knowledge across Skyrim. Mark roads, shelters, threats, caches, hunting grounds, ore veins, ingredients, contacts, and reports worth passing on.

    Keep entries clear, current, and useful. The Atlas menu can share selected entries, receive another field copy, or save a picture of the current view.

    Good maps save lives.
    Ranger-Captain Lorn Valecroft

    Atlas Instructions

    Using the Field Atlas

    Choose what you need to do, then follow the short steps. Your atlas saves automatically in this browser.

    1

    Add Entries

    1. Switch to Edit Atlas.
    2. Choose Mark, Trail, or Range.
    3. Place or draw on the map.
    4. Select every category that fits the entry, then fill in confidence and notes.
    5. Use the checkmark beside the entry to keep it.
    6. To reposition a marker, select it and choose Move, then confirm or cancel the new position.
    2

    Find Entries

    1. Stay in Field View for a read-only map and live Trailmark tools.
    2. Open Browse Atlas to use Search, Mapped By, and category filters.
    3. Select an entry to zoom to it and open its Details.
    4. Hold Ctrl, Cmd, or Shift while selecting to choose several entries.
    5. With several entries selected, use Delete in the inspector to remove them together.
    6. Press Esc to clear active filters.
    3

    Share Entries

    1. Open the Atlas menu at the top right.
    2. Share Entries creates a code or ready-to-post Field Report.
    3. Receive Entries reviews an official copy, Skyrim references, or another Ranger's code.
    4. Save Map Image downloads the current visible map as a PNG.
    4

    Clean Up

    1. Undo reverses your most recent change.
    2. Scrape Entries in the Atlas menu removes chosen categories from custom entries, Skyrim references, or the entire map.
    3. Use Undo immediately if you remove the wrong set.
    5

    Visit Trailmarks

    1. Use Field View and enter your Ranger name under Signed As.
    2. Enable Live position and Record visits.
    3. Use Link Discord once if you want nearby Trailmark channels to open automatically.
    4. The desktop Ranger Atlas integration must be installed before Live position can connect.
    5. Remain within roughly 75 metres of an official Guild Trailmark for 12 seconds to record your visit.
    6. After a recorded visit, select that Trailmark and use Leave Drop to post into its Discord channel.

    Display

    Map display

    Show names above visible entries with the setting here. Use the moon or sun at the top right to change the interface theme. With the Ranger Atlas integration installed, switch on Live position to show your local in-game location. Share position separately opts your latest point into Marshal Overwatch; it expires when updates stop. Record visits shares only your entered name, the official Trailmark, and the time you reached it. Visible labels and the live marker are included in Save Map Image.

    Map crowded? Zoom in for full Skyrim reference symbols, or use the category filters to narrow the view.

    Trailmark Access

    Link Discord

    Run /atlas link in the Ranger Discord, then enter the one-time code below. This only tells Wayfinder which Discord account should receive temporary Trailmark channel access.

    Receive Atlas

    Choose What to Add

    Select a source to preview its entries. Nothing on your atlas changes until you confirm.

    Official GUILD Atlas Refresh the maintained Ranger copy while keeping your personal notes.
    Skyrim Locations Add vanilla map and compass locations as reference markers.
    Or use a Ranger's code

    Share Entries

    Choose Entries to Share

    Select the marks, trails, and ranges to include. Printed cities and towns are never included.

    Field Report copies Discord-ready text with the same Atlas code and a compact entry summary.

    Guild Atlas

    Publish Official Copy?

    This will replace the official Guild Atlas with the selected entries.

    Anyone who loads the Guild Atlas code will receive this official copy. Personal notes on their own map are left alone.

    Archive Recovery

    Recover every unique entry ever retained from an uploaded share code or Guild Atlas publication. Recovered entries are added to this browser only.

    Overwatch

    View Rangers who have explicitly enabled Share position. Only their latest point is retained, and stale positions disappear automatically.

    Trailmark Field Drop

    Leave a Drop

    Wayfinder will post this message into the private Trailmark channel under your linked Discord identity. You must have recorded a visit here within the last 30 minutes.
