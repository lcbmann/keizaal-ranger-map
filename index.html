    Atlas Instructions

    Using the Field Atlas

    Open a section for the task you need. Your atlas saves automatically in this browser.

    1 Start hereThe basic map workflow
    1. Use Field View to browse and navigate. Use Edit Atlas to change your own copy.
    2. Use Sign in with Discord to verify Ranger membership. Your verified Ranger name is then filled in automatically.
    3. Click a map symbol or open Browse Atlas to search, filter, and view details.
    4. Use Settings to show location names and the moon or sun button to change the theme.
    2 Add and edit entriesMarks, trails, ranges, and notes
    1. Switch to Edit Atlas, then choose Mark, Trail, or Range.
    2. Place a mark, or click and drag to draw a trail or range boundary.
    3. Choose every category that fits, then add a title, confidence level, and useful notes.
    4. Use the map checkmark to save the new entry or the X to discard it.
    5. To move an existing entry, select it, choose Move, then confirm or cancel the new position.
    6. Hold Ctrl, Cmd, or Shift while selecting to select several entries. Use Delete in the inspector to remove them together.
    7. Trailmark, City, and Town are protected categories. Only verified Ranger Marshals and higher officers can create or edit these official locations.
    3 Share and receiveMove atlas information between Rangers
    1. Share Atlas creates a short code from the entries you choose, or creates a ready-to-post Field Report.
    2. Give the code to another Ranger. They open Receive Atlas, paste it, review the preview, and choose Add to My Atlas.
    3. Official Trailmarks, Cities, and Towns are always present and refresh automatically. They are not included in share codes and cannot be replaced or deleted.
    4. Review Official Atlas refreshes any other maintained GUILD entries while keeping your personal notes.
    5. Use Receive SKYRIM Locations to add or refresh vanilla Skyrim reference markers.
    6. Save Map downloads the currently visible map and labels as a PNG.
    4 Install the game linkOptional desktop mod for live position
    1. Download the latest Ranger Atlas SKSE release from the Nexus Mods page or the GitHub Releases page.
    2. In Vortex, open Mods, choose Install From File, and select the downloaded archive.
    3. Enable and deploy the mod in the same Skyrim profile used for Keizaal Online.
    4. Launch Skyrim through the normal Keizaal launcher. Keep this Atlas open in a desktop browser while you play.
    5. Return to Field View and enable Live position. The left rail should change to Skyrim connected.
    6. This game link is for desktop Skyrim. It does not provide live position on a phone or tablet.
    5 Visit TrailmarksRecord visits and leave field drops
    1. With Skyrim connected, enable Record visits. The visible boundary around official Trailmarks shows the check-in area.
    2. Stay inside the boundary for about 12 seconds. Your visit is recorded automatically and the Trailmark details open.
    3. Open Link Discord and choose Sign in with Discord. Wayfinder verifies your Ranger membership and any officer permissions. A one-time /atlas link code remains available as a fallback.
    4. After a visit, click Leave Field Drop on the arrival notice or in the Trailmark details. Write the message and submit it through the Atlas.
    5. The drop is sent to the Trailmark channel through Wayfinder. Recent visitors and drop status appear in the Trailmark details.
    6 Undo and clean upRemove entries without losing control
    1. Undo reverses your most recent change, including a receive or cleanup action.
    2. Clean Up lets you remove selected categories from custom entries, Skyrim references, or the whole map.
    3. Choose the scope and categories carefully, then use Undo immediately if you scraped the wrong entries.
    4. Official Cities, Towns, and Trailmarks are retained when you clean your own entries. Use their category filters when you want to hide them.

    Game link unavailable? Make sure the mod is enabled and deployed in Vortex, Skyrim was launched through Keizaal, and the Atlas is open in the same desktop session.
