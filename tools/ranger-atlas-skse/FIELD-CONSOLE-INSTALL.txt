Ranger Atlas Field Console 0.10.1

1. Install the included RangerAtlas.dll with Vortex, or copy it to:
   Data\SKSE\Plugins\RangerAtlas.dll

2. Install SKSE Menu Framework as an SKSE DLL dependency:
   https://www.nexusmods.com/skyrimspecialedition/mods/120352

3. Keep the Ranger Atlas page open in a browser. Enter your name, link Discord
   once if you use Trailmark field drops, and enable Live position.

4. Enter the outdoor Skyrim world, then press F7 to open the interactive Field
   Console. It captures the cursor so its tabs, buttons, and text fields work.

5. Select "Travel with map open" to release Skyrim's controls and leave a
   compact live map on screen while moving. Press F7 to close it. Press F7
   again whenever you need the interactive console.

The package includes the compact Atlas map used by the Field Console. Keep the
Data\\SKSE\\Plugins\\RangerAtlas\\field-map.jpg file installed alongside the DLL.

The console never installs an ESP/ESM/ESL and does not use Skyrim Platform
JavaScript. If SKSE Menu Framework is missing, Ranger Atlas remains safe and
F7 only displays a notification.
